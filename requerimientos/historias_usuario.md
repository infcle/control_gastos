# Historias de Usuario

Usando el formato estándar de historias de usuario (basado en BDD), aquí se detallan las historias clave para el sistema de control de gastos.

1. **Como usuario registrado, quiero registrar un gasto para rastrear mis compras diarias.**
   - Criterios de aceptación: Incluir fecha, monto, producto, proveedor y categoría. Validar datos obligatorios.

2. **Como administrador, quiero gestionar productos para mantener un catálogo actualizado.**
   - Criterios de aceptación: Crear/editar productos con nombre, precio actual y categoría. Ver historial de precios.

3. **Como usuario, quiero clasificar productos en categorías para organizar mis gastos.**
   - Criterios de aceptación: Asignar categorías predefinidas o crear nuevas. Filtrar gastos por categoría.

4. **Como administrador, quiero registrar proveedores para asociarlos a productos y gastos.**
   - Criterios de aceptación: Agregar/editar proveedores con nombre y contacto. Vincular a productos.

5. **Como usuario, quiero definir presupuestos por categoría para controlar mis finanzas.**
   - Criterios de aceptación: Establecer límites mensuales. Mostrar alertas si se supera el presupuesto.

6. **Como usuario, quiero ver el historial de precios de un producto para comparar compras.**
   - Criterios de aceptación: Lista de precios históricos con fechas. Integrar en vista de producto.

7. **Como administrador, quiero generar reportes de gastos para analizar tendencias.**
   - Criterios de aceptación: Reportes por fecha, categoría o proveedor. Exportar a PDF/CSV.

8. **Como usuario, quiero autenticarme para acceder a mis datos personales.**
   - Criterios de aceptación: Login seguro, roles (usuario/admin). Integrar con el sistema de login existente.
